# MechanicIA

Aplicación de escritorio de **mecánico inteligente**: describe el problema de tu vehículo
y la IA te ayuda a diagnosticarlo, con historial de diagnósticos y mantenimiento.

## Estructura

```
MechanicIA/
├── desktop/   # App de escritorio (Electron + React + TypeScript)
└── server/    # API REST (Node.js + Express, arquitectura MVC, JWT, PostgreSQL)
```
